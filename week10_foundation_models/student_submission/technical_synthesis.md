I learned that the specific wording of the task in the prompt is very important for turning a model's response into useful robot behavior. In mission 1, the specific wording of my requests affected the results because the ambiguous request led to the response that the robot can inspect the object by moving its camera and can navigate to the object with its wheels which isn't useful without the specific object while my improved request is more specific in starting at base, the cup object, and the shelf destination, leading to a better response of starting from base, going to the shelf, inspecting the cup, and reporting that the cup is empty. In mission 2, the visible evidence affected the results because the description of the task in the prompt with relation to the visible evidence in the photograph resulted in the better response of a circle cutter instead of a measuring tape for the "decide" task despite still being incorrect about the visible metal drawing compass in the photograph. In mission 3, the action checks affected the results by blocking the robot from moving up into the wall in row 1, resulting in the robot oscillating up and down between positions [7, 1] and [7, 2] when the robot started trying to move down. One remaining limitation of turning a model's response into useful robot behavior is that even with specific wording, the robot may still fail to complete the task because it doesn't fully understand the full setting from the prompts as seen in the plan in mission 1 which doesn't generate actual robot movement, the failure to decide the exact tool for the specified task in mission 2, and the failure to reach the goal in mission 3 despite specific wording in the route to take.
